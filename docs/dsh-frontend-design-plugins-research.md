# Плагины DSH для frontend и UI/UX проекта

Проверено 11 ноября 2026. Отбор — по пригодности для **интерфейса разрабатываемого проекта**, а не для оформления самой DSH. Источники поиска: [каталог awesome-dsh-plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin), его [машиночитаемый индекс](https://cdn.jsdelivr.net/npm/dsh-plugin-catalog/index.json) и [поиск GitHub по topic](https://api.github.com/search/repositories?q=topic%3Adsh-plugin&per_page=100). Topic сам по себе не доказывает, что репозиторий — нативный плагин: ниже у всех восьми npm-манифест содержит `dsh.bundle.patch`. Функциональность — по описанию авторов, не результат нашего запуска.

**Метрики:** звёзды GitHub на момент проверки; загрузки npm — за 3–9 ноября 2026 включительно. Это загрузки пакета, не число пользователей; звёзды относятся ко всему репозиторию и не доказывают качество или безопасность. Список не является рейтингом экосистемы. Версия и `engines` — из ссылки «манифест»; отсутствие `engines.dsh` означает, что совместимость с установленной DSH 0.2.2-rc.1 не подтверждена одним лишь манифестом.

## Восемь практичных кандидатов

Данные перенесены из отдельного ui-ux-pro-max-skill; это именно DSH-бандл, а не просто ссылка на чужой skill. Подходит для выбора стилей и правил, не заменяет визуальную проверку. Версия 1.4.1, Node `^22.19 || >=24`; DSH engine не заявлен, есть ограничения peer-зависимостей. **29 звёзд / 1226 загрузок**. Использует браузер; автор отдельно предупреждает, что некоторые цветовые синтаксисы пропускаются, а пороги нужно подбирать под продукт. ## Что выбрать и что осталось непроверенным

Для обычного frontend-проекта практичная связка для дальнейшей оценки — **ui-ux-pro-max или commercial-ui-ux** для правил, **dsh-design** для измерений и **annotate-browser** для указания конкретных мест; для статического HTML вместо последнего проще рассмотреть **html-annotate**. Figma и Stitch — только при необходимости их внешних сервисов. Это рекомендации по назначению, не результат сравнительного тестирования.

Другой вариант выбора элементов — [dsh-visual-annotator](https://github.com/ZhongqiXiao/dsh-visual-annotator): [npm-манифест 0.5.3](https://registry.npmjs.org/dsh-visual-annotator/latest) подтверждает DSH bundle, но текущий README репозитория уже называет пакет `dsh-annotator` версии 0.5.4; перед выбором нужно отдельно проверить переименование и актуальный пакет. Для старого имени [npm API](https://api.npmjs.org/downloads/point/2026-11-03:2026-11-09/dsh-visual-annotator) показывает 330 загрузок, [GitHub API](https://api.github.com/repos/ZhongqiXiao/dsh-visual-annotator) — 0 звёзд.

Исследование ограничено публичными каталогом, поиском и документацией: полнота не гарантирована, показатели быстро меняются; совместимость кроме явно указанных диапазонов, безопасность исходников, фактическое качество генерации и end-to-end работу не проверяли. Установка, авторизация, доступ к локальному профилю и изменение конфигурации не выполнялись. Перед установкой стороннего кода отдельно проверить его исходники, разрешения и точные требования.
