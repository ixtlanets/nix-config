# OpenCode Go: бюджет и лимиты

Проверено **2026-11-10, Europe/Moscow** по официальным страницам и публичным скриптам Console, без входа в аккаунт. Через доступный GUI-инструмент окно браузера не обнаружено; личный остаток и настройки пользователя не проверены. Secrets не читались.

## Краткие выводы

1. **43,330 requests — оценка на 5 часов для базового Go, не гарантированная квота запросов и не месячный пакет.** На лендинге колонка называется **“Est. requests / 5 hr”**. Документация для DeepSeek V4.1 Flash даёт **43,330 / 5 часов; 108,330 / неделю; 216,670 / месяц**; для Go Plus — **86,670 / 216,670 / 433,330**. Источники: [лендинг](https://opencode.ai/console/go), [Estimated requests](https://opencode.ai/docs/console/go/#estimated-requests), [полная Markdown-версия с вкладками тарифов](https://opencode.ai/docs/console/go.md).

2. **Учитывается стоимость токенов, а не просто число вызовов.** Цитаты: “Usage limits are defined as monthly dollar amounts”; “The tables below estimate request counts based on typical Go usage patterns”; “actual usage varies”. Для Flash оценка предполагает **410 input + 71,300 cached + 310 output tokens на запрос**. Поэтому длиннее ответ, меньше cache hits и другой профиль запросов меняют достижимое количество; это не обещание 43 тысяч пользовательских задач. Источник: [Usage limits / Estimated requests](https://opencode.ai/docs/console/go/#usage-limits).

3. **Окна действуют совместно: 5 часов — 20%, неделя — 50%, месяц — 100% месячного лимита.** Для Flash таблица Go показывает эквивалент **$100/месяц**, то есть **$20 / 5 часов и $50 / неделю**; Go Plus — **$200**, соответственно **$40 и $100**. Это арифметика по опубликованным процентам, а не отдельные пополняемые кошельки. Даже при восстановлении короткого окна месячный предел остаётся. Источники: [Usage limits](https://opencode.ai/docs/console/go/#usage-limits), [таблицы Go и Go Plus](https://opencode.ai/docs/console/go.md).

4. **Общий ли бюджет между моделями — публичная формулировка не даёт безусловного ответа.** Она говорит: “Each model's monthly limit below determines how its usage counts toward those allowances”. API определяет `opencode.allowance` как “how much the request counted toward your usage limits, in dollars of the plan’s monthly limit”. Это согласуется с **общим нормированным allowance и разным весом моделей**, но ни явного “shared across models”, ни формулы смешанного расхода в проверенных текущих страницах нет. Поэтому **нельзя обещать независимые полные пакеты на каждую модель**, суммировать строки таблицы или уверенно утверждать, что переключение модели обходит лимит. Общность счётчика и формулу следует подтвердить у поддержки либо контролируемым сравнением usage в собственном аккаунте. Источники: [Usage limits](https://opencode.ai/docs/console/go/#usage-limits), [Inference API: Cost](https://opencode.ai/docs/console/api/inference/#cost).

5. **После исчерпания включённого usage запросы блокируются, если не включён Extra Usage.** При включённом **Extra Usage** и наличии средств запросы переходят на **pay-as-you-go balance**, то есть дальше расходуются отдельные оплаченные credits. Бесплатные модели остаются вариантом продолжения; автоматическое переключение на них не обещано. **Go Teams** начинает с Extra Usage **включённым**; для Go/Go Plus текущий текст не фиксирует начальное значение — надо смотреть настройку. Источник: [Usage beyond limits](https://opencode.ai/docs/console/go/#usage-beyond-limits).

6. **Когда закончились и платные credits, платные запросы возвращают HTTP 402; баланс не уходит в минус.** Это описание отсутствия денег, а не подтверждённый HTTP-код именно Go rate limit. Auto-recharge — отдельная настройка, способная докупать credits при низком балансе. Источник: [Billing](https://opencode.ai/docs/console/billing/#when-credits-run-out).

7. **Peak/off-peak влияет на скорость расхода.** Для Flash Go публикует цены за 1M токенов input/output/cached read: **$0.15/$0.60/$0.003 off-peak**, **$0.30/$1.20/$0.006 peak**. Peak: **01:00–04:00 и 06:00–10:00 UTC, понедельник–пятница**; остальное off-peak. При одинаковом профиле запросов peak вдвое дороже, поэтому оценку 43,330 нельзя воспринимать как одинаковую гарантию в любое время. Источник: [Usage limits, примечание DeepSeek](https://opencode.ai/docs/console/go/#usage-limits).

## Дополнительная проверка текущего интерфейса

Публичная страница Console загружает [компонент Go](https://opencode.ai/console/assets/go-x49wZ6Se.js), который использует [page-dialogs-DXSg9A8U.js](https://opencode.ai/console/assets/page-dialogs-DXSg9A8U.js). В последнем компонент расхода показывает **один набор** `t().meters.fiveHour`, `t().meters.week`, `t().meters.month` с подписями `5-hour window`, `Weekly`, `Monthly`; выбор модели в этом компоненте отсутствует. Таблица моделей отдельно подписана `Estimated requests per 5 hours and monthly usage limits by model`. Это дополнительное свидетельство общего нормированного бюджета, а не независимых пакетов каждой модели. Это статическое чтение текущего опубликованного клиента, не проверка backend enforcement и не наблюдение личного аккаунта. URL хешированных скриптов изменятся при следующем развёртывании.

## Что остаётся непроверенным

- **Точное начало/reset окон в текущем сервисе:** опубликованные 5h/week/month не определяют явно sliding против фиксированного 5-часового окна, день/час сброса недели и календарный против расчётного месяца. Старый код нельзя выдавать за текущий контракт. Источники текущего описания: [Go](https://opencode.ai/docs/console/go/#usage-limits); историческая реализация: [subscription.ts](https://github.com/anomalyco/opencode/blob/773d8621d6bcd311067b225d837c917b3e83573e/packages/console/core/src/subscription.ts), [date.ts](https://github.com/anomalyco/opencode/blob/773d8621d6bcd311067b225d837c917b3e83573e/packages/console/core/src/util/date.ts).
- **Исторические, а не текущие детали:** указанный старый `date.ts` считал неделю с понедельника 00:00 UTC, месяц — от даты/времени подписки; `subscription.ts` анализировал 5-часовой интервал через сохранённое `timeUpdated`. Но legacy database удалена [коммитом 2026-10-12](https://github.com/anomalyco/opencode/commit/b9ca4d21b4f241154081143a6f5bef648f5ccfd0), старый сайт — [коммитом 2026-11-06](https://github.com/anomalyco/opencode/commit/3efbdad965c78e2b3202d02717014d54082f1877), а [handler перед удалением](https://github.com/anomalyco/opencode/blob/773d8621d6bcd311067b225d837c917b3e83573e/packages/console/app/src/routes/zen/util/handler.ts) уже писал “Every request is served by new inference”. Поэтому эти детали не использованы как обещание сегодняшнего поведения.
- **Личный остаток, фактический Extra Usage, точный Go-limit HTTP-код и общность счётчиков экспериментально не проверены.** Текущая документация предлагает смотреть usage в Console; API возвращает `billing_source`, `list_cost` и `allowance`, но здесь аутентифицированные запросы не выполнялись. Источники: [Go](https://opencode.ai/docs/console/go/#estimated-requests), [Cost](https://opencode.ai/docs/console/api/inference/#cost).
