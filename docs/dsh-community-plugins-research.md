# Сторонние плагины и каталоги DeepSeek Harness

Проверено 11 ноября 2026 года. Речь именно о [DeepSeek Harness `@deepseek-ai/dsh`](https://registry.npmjs.org/@deepseek-ai%2Fdsh), а не о других проектах с именем dsh. **Экосистема существует и заметна:** есть крупный независимый каталог, маркет и опубликованные native bundles. Счётчики ниже — индикаторы интереса, не число пользователей и не гарантия качества или безопасности.

## Каталоги

- [Awesome DSH Plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin) — курируемый список сторонних устанавливаемых bundles; **24 195 звёзд** по [GitHub API](https://api.github.com/repos/awesome-dsh-plugin/awesome-dsh-plugin). Авторы публикуют [индекс для Discover](https://cdn.jsdelivr.net/npm/dsh-plugin-catalog/index.json); согласно README, он охватывает npm-пакеты с известной версией, а не все GitHub-only записи. Сам каталог предупреждает, что включение не является аудитом безопасности.
- [dsh-market](https://github.com/dsh-market/dsh-market) — сторонний интерфейс каталога внутри DSH, а не официальный каталог DeepSeek: поиск, категории и установка; [11 839 звёзд](https://api.github.com/repos/dsh-market/dsh-market), [337 435 загрузок npm](https://api.npmjs.org/downloads/point/2026-11-03:2026-11-09/dshmarket) за 3–9 ноября. Это тоже [native bundle](https://registry.npmjs.org/dshmarket/latest). По README того же проекта, в DSH 0.2.1+ можно использовать встроенный Discover с индексом выше, не устанавливая отдельный маркет.
- [Awesome DeepSeek Harness от 0xsline](https://github.com/0xsline/awesome-deepseek-harness) — более широкий тематический список плагинов, инструментов и инфраструктуры; [1 343 звезды](https://api.github.com/repos/0xsline/awesome-deepseek-harness). Его README предупреждает: часть ссылок `dsh-external` может требовать доступа к организации. Это не означает, что каждая запись — публичный совместимый bundle.

## Подключение без стороннего магазина

[Официальная документация DSH](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/user/guide/plugin-market.md) описывает встроенную поддержку сторонних индексов: Plugins → Experimental plugins → включить **Custom plugin indexes**, затем Discover → Add index source. DSH не поставляет предустановленных источников; содержимое индексов не проверяется на достоверность. Для Awesome DSH Plugin можно добавить `https://cdn.jsdelivr.net/npm/dsh-plugin-catalog/index.json`: при проверке URL вернул HTTP 200, `format: 1` и **5126 записей**. Это число записей индекса, не проверенных установок или активных пользователей.

Официальный [README DSH](https://github.com/deepseek-ai/deepseek-harness) рекомендует публичный [GitHub topic dsh-plugin](https://github.com/topics/dsh-plugin) для обнаружения плагинов. Дополнительно есть [dsh-find-plugin](https://github.com/awesome-dsh-plugin/dsh-find-plugin): по README он добавляет агенту поиск по этому topic с ранжированием по звёздам и резервным поиском по каталогу. [230 звёзд](https://api.github.com/repos/awesome-dsh-plugin/dsh-find-plugin); совместимость с текущим профилем не проверялась.

## Границы и метод

- Нативный bundle отличается от самостоятельного MCP-сервера или набора skills: например, [dsh-codebase-memory](https://github.com/andyfan1094/dsh-codebase-memory) — bundle-мост **к** отдельному MCP-серверу плюс watcher, а не сам MCP-сервер. [dsh-TUI](https://github.com/ccch1mneyyy/dsh-TUI) описывает переход к отдельному приложению с DSH как backend; его не следует автоматически считать обычным плагином профиля.
- Сторонний код получает права процесса пользователя; инструментальные подтверждения не изолируют такой код. Перед установкой стоит проверить исходники, зависимости, версии хоста и сетевые/секретные доступы; авторы [каталога прямо предупреждают об этом](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin).
- Поиск: [GitHub repositories «deepseek harness plugin»](https://api.github.com/search/repositories?q=deepseek+harness+plugin&sort=stars&per_page=30), [«@deepseek-ai/dsh»](https://api.github.com/search/repositories?q=%22%40deepseek-ai%2Fdsh%22&per_page=100), [npm «deepseek-harness»](https://registry.npmjs.org/-/v1/search?text=deepseek-harness&size=250), `keywords:dsh-plugin`, затем README проектов, npm `latest` и APIs звёзд/загрузок. Поиск ограничен публично индексируемыми источниками, ранжированием и выборкой; не является полным рейтингом. Значения скачиваний могут включать повторные и автоматические установки.
- Ничего не устанавливалось и конфигурация DSH не изменялась; код, лицензии, безопасность и совместимость конкретных версий не аудировались. Описания возможностей — заявления авторов, не результаты испытаний.
